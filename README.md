# Online-Task-Management-System
It is a web based tool used by companies or teams to assign tasks, track progress and improve productivity.
Managers can assign and monitor tasks, while employees can view and update the tasks assigned to them.

## Features
- User authentication (Manager & Employee)
- Task creation and assignment
- Task status tracking (To Do / In Progress / Completed)
- Dashboard for managing tasks
- User-friendly interface

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git & GitHub
